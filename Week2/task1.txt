1. Write the corresponding project description
I am working for a software company, with the goal of designing a Location Based Shopping Application (LBSP).
The desired application can run on any resource-bounded device, which includes smart devices such as smartphones.
The application should be able to find nearby stores using the Google Maps API, and based on the user location.
As the user moves around, new shops may be dynamically added to nearby shops.
Each shop should display a list of items currently available.
The user can select items that are available in stores and add them to their shopping list.
They should be able to see what items from the list need to be purchased from the shop.
The application should prompt the user whether to share a deals list via SMS or emails to others.
A customer's authentication should be achieved by a login page, authentication cookies, or single sign-on.
Payment should be done using credit card and external credit payment service or with PayPal.
